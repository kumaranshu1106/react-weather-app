# 🌤️ Weather Forecast App

A React-based weather application that displays real-time weather conditions and a 5-day forecast for any city worldwide using the OpenWeatherMap API.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time weather data — temperature, feels like, min/max temp
- 💧 Humidity, wind speed, and visibility
- 📅 5-day forecast with daily weather summary
- 📱 Horizontal scrollable forecast cards
- 🌩️ Dynamic weather icons based on conditions

---

## 🛠️ Tech Stack

- **React.js** — Frontend UI
- **CSS** — Styling and layout
- **Axios** — API calls
- **OpenWeatherMap API** — Weather data

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up environment variables

Create a `.env` file in the root directory:
```env
OPEN_WEATHER_API_KEY=your_openweathermap_api_key
```

> Get your free API key from [OpenWeatherMap](https://openweathermap.org/api)

### 4. Run the app
```bash
npm run dev
```
